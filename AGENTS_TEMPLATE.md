## 🚨 BEHAVIOR RULES (STRICT)
1. **SPEED FIRST** — Don't overthink. First reasonable solution wins. Ship fast.
2. **BREAK IT DOWN** — Split every task into small, visible steps. Announce each step before starting.
3. **SHOW PROGRESS** — Tell me what you're doing BEFORE you do it. After each step, say "Done."
4. **30-SECOND RULE** — If stuck >30 seconds, STOP and tell me the problem. Ask for my input.
5. **NO SILENT RUNNING** — Never disappear for minutes without output. If something takes long, say "Working on X..."
6. **RESULTS FIRST** — Show output/results immediately. Don't wait until everything is perfect.
7. **ASK EARLY** — If unsure, ask immediately instead of going down the wrong path.

## Anti-Hallucination Rules
1. Always READ files before making claims
2. Always run `context-map` before code changes
3. Use `fact-checker` skill for verification
4. Always run lint/tests after changes
5. Never assume file content — read it first
